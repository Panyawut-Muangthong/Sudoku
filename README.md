# เว็บเกมซูโดกุภาษาไทยสำหรับทุกคน (Accessible Thai Sudoku)
> ถอดแบบฟีเจอร์และดีไซน์จาก [Sudoku.com/th](https://sudoku.com/th) พร้อมรองรับผู้พิการทางสายตา (Blind & Visually Impaired) ให้สามารถเล่นได้อย่างสมบูรณ์แบบ 100%

---

## 🌟 ฟีเจอร์หลัก (ถอดแบบจาก Sudoku.com)

1. **ดีไซน์สะอาดตา สไตล์ Sudoku.com**:
   - ตาราง 9x9 พร้อมเส้นขอบแบ่งบล็อก 3x3 ชัดเจน
   - ไฮไลต์ช่องที่เลือก, ไฮไลต์แถว คอลัมน์ บล็อกเดียวกัน, และไฮไลต์ตัวเลขที่ตรงกัน
   - ตัวเลือกระดับความยาก 4 ระดับ: **ง่าย**, **ปานกลาง**, **ยาก**, **ผู้เชี่ยวชาญ**
2. **ระบบการเล่นแบบครบวงจร**:
   - **บันทึก (Pencil Notes)**: ใส่ตัวเลขตัวเลือกขนาดเล็กในช่องว่าง พร้อมระบบลบโน้ตอัตโนมัติเมื่อใส่เลขจริง
   - **ตัวนับข้อผิดพลาด**: จำกัด 3 ครั้ง (`0/3`) พร้อมหน้าต่างแจ้งจบเกมเมื่อครบกำหนด
   - **คำใบ้อัจฉริยะ (Smart Hint)**: อธิบายเหตุผลขั้นตอนการคิดเป็นภาษาไทย (เช่น "ช่องว่างสุดท้ายในแถว", "ตัวเลขเดี่ยวที่เป็นไปได้")
   - **เลิกทำ (Undo)**: ย้อนกลับการกระทำได้ไม่จำกัด
   - **ลบ (Erase)**: ลบตัวเลขหรือโน้ตในช่อง
   - **ตัวนับตัวเลขที่เหลือใน Numpad**: แสดงจำนวนเลขที่ยังไม่ได้ใส่ (1-9) และจางลงเมื่อครบ 9 ตัว
   - **ตัวจับเวลา (Timer)** พร้อมปุ่มหยุดชั่วคราว (Pause/Resume)

---

## ♿ ฟีเจอร์พิเศษสำหรับผู้พิการทางสายตา (Accessibility Highlights)

1. **การควบคุมผ่านแป้นพิมพ์ 100% (Full Keyboard Navigation)**:
   - ใช้ปุ่มลูกศร `↑` `↓` `←` `→` หรือ `W` `A` `S` `D` เพื่อเลื่อนสำรวจช่องในตาราง 9x9 ได้อย่างอิสระ
   - โครงสร้างตามมาตรฐาน **W3C ARIA Grid** (`role="grid"`, `role="gridcell"`, `aria-rowindex`, `aria-colindex`)
2. **ระบบเสียงบรรยายภาษาไทยในตัว (Web Speech TTS)**:
   - บรรยายตำแหน่งและสถานะของช่องทันทีที่เลื่อนโฟกัส เช่น *"แถว 3 คอลัมน์ 5, บล็อก 2, ตัวเลข 7 เป็นโจทย์"* หรือ *"แถว 1 คอลัมน์ 2 ว่าง โน้ตตัวเลข 1, 4"*
   - แจ้งเตือนข้อผิดพลาดและการกระทำทั้งหมดเป็นเสียงภาษาไทย
3. **รองรับโปรแกรมอ่านจอภาพสากล (Screen Readers)**:
   - รองรับ **NVDA**, **JAWS**, **VoiceOver (iOS/macOS)** และ **TalkBack (Android)** ผ่าน `aria-live="polite"` และ `aria-live="assertive"`
4. **สังเคราะห์เสียงเอฟเฟกต์เชิงพื้นที่ (Web Audio API Synthesizer)**:
   - ระดับเสียง (Frequency) เปลี่ยนแปลงตามพิกัดแถวและคอลัมน์ ช่วยให้ผู้เล่นรู้สึกถึงตำแหน่งบนกระดานได้จากระดับเสียง
   - เสียงต่างกันระหว่าง "ช่องโจทย์", "ช่องที่ผู้เล่นกรอก", และ "ช่องว่าง"
   - เสียงชนขอบกระดานเมื่อเลื่อนออกนอกตาราง, เสียงเมื่อข้ามบล็อก 3x3, เสียงถูก, เสียงผิด, และเสียงฉลองเมื่อชนะ
5. **ปุ่มลัดสแกนตารางด้วยเสียง (Audio Quick Scan Shortcuts)**:
   - กด `R`: อ่านตัวเลขทั้งหมดในแถวปัจจุบัน (Row)
   - กด `C`: อ่านตัวเลขทั้งหมดในคอลัมน์ปัจจุบัน (Column)
   - กด `B`: อ่านตัวเลขทั้งหมดในบล็อก 3x3 ปัจจุบัน (Block)
   - กด `Space` หรือ `Enter`: ทวนข้อมูลของช่องปัจจุบัน
6. **โหมดคอนทราสต์สูง (High Contrast Dark Mode)**:
   - พื้นหลังสีดำสนิท ตัวเลขและขอบสีเหลือง/ฟ้าสว่างสดใส ผ่านมาตรฐานความเปรียบต่างระดับสูง (WCAG AAA) สำหรับผู้มีสายตาเลือนราง (Low Vision)

## ⌨️ สรุปปุ่มลัดแป้นพิมพ์ (Keyboard Shortcuts)

| ปุ่มกด | การทำงาน |
| :--- | :--- |
| `↑` `↓` `←` `→` หรือ `W` `A` `S` `D` | เลื่อนโฟกัสไปยังช่องต่างๆ บนกระดาน 9x9 |
| `1` ถึง `9` | กรอกตัวเลข (หรือใส่/ลบโน้ตเมื่ออยู่ในโหมดบันทึก) |
| `Backspace` หรือ `Delete` | ลบตัวเลขหรือโน้ตในช่องที่เลือก |
| `N` หรือ `P` | สลับโหมดจดบันทึก (Notes Mode On / Off) |
| `Space` หรือ `Enter` | ฟังข้อมูลช่องปัจจุบันซ้ำ (หรือเล่นต่อเมื่อหยุดชั่วคราว) |
| `R` | อ่านข้อมูลตัวเลขทุกช่องใน **แถว (Row)** ปัจจุบัน |
| `C` | อ่านข้อมูลตัวเลขทุกช่องใน **คอลัมน์ (Column)** ปัจจุบัน |
| `B` | อ่านข้อมูลตัวเลขทุกช่องใน **บล็อก 3x3 (Block)** ปัจจุบัน |
| `U` หรือ `Ctrl + Z` | เลิกทำการกระทำล่าสุด (Undo) |
| `H` | ขอคำใบ้พร้อมคำอธิบาย (Smart Hint) |
| `?` หรือ `F1` | เปิดหน้าต่างคู่มือปุ่มลัด |
| `Escape` | ปิดหน้าต่าง Popup / Modal |

---

## 🚀 วิธีการเปิดใช้งาน

คุณสามารถเปิดใช้งานเว็บเกมนี้ได้ 2 รูปแบบง่ายๆ:

### รูปแบบที่ 1: ดับเบิลคลิกเปิดไฟล์ได้ทันที (ไม่ต้องติดตั้งโปรแกรมเพิ่ม)
- ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดเล่นในเบราว์เซอร์ (Chrome, Edge, Firefox, Safari) ได้ทันที

### รูปแบบที่ 2: รันผ่าน Local Server
เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
npm start
```
หรือ
```bash
python -m http.server 3000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
